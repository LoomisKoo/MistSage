# 法律文案（GitHub Pages）

1. 新建公开仓库，例如 `CostLedger-pages`
2. 把本目录的 `privacy.html`、`terms.html` 放到仓库根目录
3. 开启 GitHub Pages（Deploy from branch / root）
4. 确认可访问：
   - `https://<user>.github.io/CostLedger-pages/privacy.html`
   - `https://<user>.github.io/CostLedger-pages/terms.html`
5. 若用户名/仓库名不同，改 App 内 `LegalDocument.url`（`LegalWebView.swift`）

当前 App 默认指向：`https://loomiskoo.github.io/CostLedger-pages/`
